# fetcher никогда не пишет archive.jsonl

`main()` отбрасывает статьи старше `INBOX_HORIZON_HOURS` при сборке нового inbox
(`if pub_dt >= cutoff`, строка 268) и только потом, на шаге 4 (строки 340–349),
перечитывает уже отфильтрованный inbox в поисках просроченных. Список `expired`
всегда пуст: в логах 12 445 записей `archived 0`, файла `archive.jsonl` на диске
никогда не было, хотя README (дерево файлов) и докстринг fetcher.py его обещают.
Статьи старше 72 часов молча пропадают.

Починка механическая: собирать `expired` из старого inbox до фильтрации. Но архив
будет расти на ~3 тыс. статей в сутки, его надо добавить в .gitignore и решить,
нужен ли он вообще.

Нерешённое: нужна ли история старше 72 часов. Она понадобится, если делать
[search-news-tool](search-news-tool.md) или разбирать фидбек по старым выпускам;
если нет — правильнее удалить мёртвый код архивации и строку из README.
