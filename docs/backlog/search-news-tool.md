# MCP-тул search_news(query, lang) по inbox

`list_news` фильтрует по источнику и времени, текстового поиска нет. В inbox
~10 тыс. статей за 72 часа. Прод-потоки (`digest_context`, `watchman_context`)
в поиске не нуждаются: они получают готовые кластеры, и по принципу «платят за
ходы» лишний тул им только вредит.

Нерешённое: появится ли интерактивный сценарий («а что было про X» в ответ на
дайджест или в Telegram), ради которого тул стоит делать. Поиск по архиву
невозможен, пока не решён [fetcher-never-writes-archive](fetcher-never-writes-archive.md).
